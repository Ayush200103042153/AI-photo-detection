In this project, I built an AI image detection website where a user can upload a photo and the system checks how likely it is to be AI-generated. I used HTML, CSS, and JavaScript for the website design and user interface, and Python with FastAPI for the backend. I also connected an AI detection API to get a real confidence percentage for each image. If the score is below 40%, the image is shown as legit, from 40% to 99% it says it might be AI-generated, and at 100% it is marked as AI-generated. I also added features like image preview, video input rejection, a space-themed design with animations, and a reset option to scan another image. The project is hosted online using Render and the code is stored on GitHub.
